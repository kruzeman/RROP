# Участие в разработке RROP

[English](CONTRIBUTING.md)

RROP посвящён Rings of Power: рекомпиляции, аппаратному runtime, отображению
и инструментам сборки. Профили других игр остаются в GenesisRecomp.

Работайте в отдельной ветке и присылайте pull request с описанием проблемы,
нового поведения и фактически выполненных проверок. Различайте чтение кода,
синтетические тесты и проверку с настоящим ROM: они не подтверждают полное
прохождение игры.

Для сообщения об ошибке нужны commit, ОС, компилятор, команды сборки и
запуска, режим звука и последние строки терминала. Для игрового сбоя — место
и последовательность действий. При ошибке Void приложите текстовый отчёт,
описанный в [диагностике](docs/diagnostics-ru.md).

Не публикуйте ROM, сгенерированный игровой C, executable с данными игры,
извлечённые ресурсы или полные снимки машины. Тесты пишите на синтетических
данных. Перед публикацией диагностического отчёта проверьте его содержимое.

```sh
make test
make demo
```

Проверки используют unittest, C/C++ и SDL2/SDL2_ttf. Тесты с оригинальным ROM
пропускаются, если его нет. Windows CI работает через MSYS2 UCRT64.

Сохраняйте лицензии зависимостей. Собственные изменения в код проекта
предоставляются под MIT.
