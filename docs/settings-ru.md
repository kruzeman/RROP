# Settings в Rings of Power

В RROP настройки открываются шестым пунктом главного меню,
через **System → Settings** во время игры или клавишей **F10**.
Исходные пункты обоих меню сохранены. Окно настроек оформлено свитком из
графики игры; внешние шрифты используются, если задан `--font`.

**Mode: Classic** («Классика») оставляет оригинальный размер изображения,
шрифт и управление клавиатурой. Сохранения продолжают работать.
**Mode: Enhanced** («С фишками») показывает дополнительные пункты:

| Пункт | Действие |
| --- | --- |
| Widescreen | Расширенный мир с интерфейсом поверх него |
| Fullscreen | Полный экран с разрешением рабочего стола |
| Smooth map | Плавная камера и движение героя на карте и в помещениях |
| Zoom | Колесо мыши: масштаб 50–100%, средняя кнопка / `0`: 100% |
| Mouse controls | ЛКМ: ходьба; ПКМ: штатный автоход A + направление |
| Control settings | Заглушка будущей настройки клавиш и геймпадов |

Сглаживание и мышь работают независимо от переключателя колеса: с выключенным
Zoom масштаб равен 100%. В помещениях и боях сохраняется стандартная рамка и
масштаб 100%, даже при включённых улучшениях. При возвращении к Enhanced
восстанавливаются индивидуальные переключатели. Полноэкранный режим также
отключается при выборе Classic.

Герой и камера сглаживаются на карте и в помещениях; в маленькой комнате камера остаётся
неподвижной, а сглаживается движение героя. [Подробности](native-motion-ru.md).

Стрелки вверх/вниз выбирают пункт, Enter / X / Z переключают его; стрелки
влево/вправо тоже переключают. **Esc** возвращает назад, **F10** закрывает
настройки. Внутри заглушки Control settings Enter также возвращает назад.
Пока окно открыто, игра, звук и отсчёт пяти минут до автосохранения стоят на
паузе. Накопленные нажатия и незавершённые жесты мыши сбрасываются.

Изменения сразу записываются в **settings.cfg** рядом с игровыми сохранениями:

- Linux: `$XDG_STATE_HOME/genesisrecomp/rings-of-power`, либо
  `~/.local/state/genesisrecomp/rings-of-power`;
- Windows: `%LOCALAPPDATA%/GenesisRecomp/rings-of-power`;
- с `--save-dir`: в указанной папке.

Настройки отдельны от слотов: загрузка игры не меняет выбранный режим.
Сохранённый settings.cfg имеет приоритет над начальными флагами запуска,
включая флаги из Windows Play.cmd. Для возврата к начальному выбору закройте
игру и удалите только settings.cfg; игровые `.grs` оставьте на месте.

## Сборка

Все переключатели графики и мыши теперь входят в обычную оконную сборку
`build_rings_of_power.py`; дополнительные сборочные флаги для них не нужны.
Внешний шрифт по-прежнему требует SDL2_ttf и `--text-renderer rings-text`:

```bash
python3 examples/build_rings_of_power.py 'roms/Rings of Power (UE) [!].gen' \
  --text-renderer rings-text

./build/rings-of-power/rings-of-power --window --audio on \
  --font '/полный/путь/к/шрифту.ttf'
```

С `--font` первый запуск выбирает Enhanced, а переключатели мира изначально
определяются флагами запуска. Без `--font` и флагов улучшений первый запуск
выбирает Classic; при первом включении Enhanced доступны все улучшения карты.
Для начального включения всех возможностей:

```bash
./build/rings-of-power/rings-of-power --window --audio on \
  --widescreen --zoom --smooth-camera --mouse --font '/полный/путь/к/шрифту.ttf'
```

Можно собрать без внешних шрифтов: уберите `--text-renderer rings-text` и
`--font`; меню настроек содержит встроенный шрифт. Звук по умолчанию — ymfm.
Для Windows используйте [обычный MinGW-скрипт](usage-ru.md#windows):

```bash
python3 examples/build_rings_windows.py 'roms/Rings of Power (UE) [!].gen'
```

Расширение пунктов относится только к проверенному ROM Rings of Power [!]
и оконному запуску. ROM не переписывается; System получает отдельную таблицу
ресурсов в адресном пространстве хоста. Базовый headless-запуск сохраняет
исходные пять пунктов главного меню.

Во время игры Esc открывает Settings вместо немедленного закрытия окна.
Пункт **Exit** внизу Settings завершает игру; **Back** и Esc внутри настроек
возвращают назад. Exit доступен и в Classic, и в Enhanced. В выборе слотов
Esc по-прежнему закрывает меню сохранения или загрузки.

Экранная подсказка геймпада (**System → Help**) по умолчанию выключена.
Этот пункт по-прежнему включает и выключает её; выбор записывается как
`help=0` / `help=1` в settings.cfg и сохраняется между запусками. При старте
игры и загрузке слота применяется этот выбор, поэтому старый сейв с
включённой подсказкой не возвращает её сам. Это настройка экранной подсказки,
а не отключение физических контроллеров.
