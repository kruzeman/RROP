# Геймпады

[English](gamepads.md) · [Мануал](usage-ru.md)

В оконной сборке SDL2 поддерживается один контроллер, распознанный через SDL
GameController API. Дополнительные библиотеки и флаги сборки не нужны. Геймпад
по умолчанию включён в Classic и Enhanced. В headless физического ввода нет.

Подключать можно до запуска или во время игры. Выбирается первый распознанный
контроллер. При отключении его кнопки отпускаются, затем ищется другой подключённый
геймпад. Клавиатура продолжает работать вместе с ним. System → Help управляет
только старой экранной подсказкой с изображением контроллера.

## Раскладка по умолчанию

Здесь используются стандартные позиции кнопок SDL, как на Xbox. Для PlayStation
X/A/B соответствуют Square/Cross/Circle — квадрату/кресту/кругу.

| Ввод | Действие |
| --- | --- |
| Крестовина или левый стик | Направления Genesis |
| X / A / B | Сеговские A / B / C |
| Start | Сеговская Start |
| Back / Select | Открыть Settings |
| LB / RB | Выбор ручного сохранения / загрузки |

Сочетания открывают новые меню проекта. Исходные меню игры получают обычные
сеговские кнопки. В Settings и выборе слотов крестовина/левый стик выбирают пункт,
A/X/Start подтверждают, B/Back возвращают назад. Между шагами в меню возвращай
стик в центр: удержание не повторяет выбор.

## Control settings

Settings → Control settings позволяет включить/отключить геймпад, увидеть имя
устройства и выбрать вторую раскладку: A/B/X контроллера → сеговские A/B/C.
Настройки сохраняются в `settings.cfg` ключами `gamepad` и `pad_layout`, отдельно
от игровых слотов. Старые файлы настроек оставляют геймпад включённым с X/A/B.
Произвольного переназначения отдельных кнопок пока нет.

Если выключить геймпад, его команды меню тоже отключатся. Для повторного
включения используй клавиатуру: она остаётся доступна.

Мёртвая зона стика — примерно 30% для включения направления и 24% для отпускания,
чтобы уменьшить дрейф. Противоположные направления взаимно отменяются. При
открытии/закрытии новых меню, паузе, загрузке сохранения и потере фокуса окна ввод
сбрасывается. Удерживаемые кнопки нужно отпустить и нажать снова: подтверждение
меню не должно превращаться в случайное действие после возврата в игру.

## Если не определяется

Проверь, видит ли устройство ОС и знает ли SDL2 его раскладку. Для неизвестных
контроллеров можно передать mapping через переменную `SDL_GAMECONTROLLERCONFIG`.
Проект не скачивает базу раскладок и не использует резервный ввод raw joystick.
Надписи на кнопках Nintendo могут отличаться от логических позиций SDL.

Поведение с физическими контроллерами ещё нужно проверить на каждой платформе.
